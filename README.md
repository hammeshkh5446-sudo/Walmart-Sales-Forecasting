# Walmart Sales Forecasting

## Project Overview
This project focuses on forecasting Walmart weekly sales using Machine Learning and analyzing retail performance through an interactive Power BI dashboard.

The project includes data preprocessing, exploratory data analysis, feature engineering, machine learning model development, and business insights visualization.

## Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering for sales forecasting
- Machine learning based sales prediction
- Streamlit prediction application
- Interactive Power BI dashboard

## Machine Learning Model
- Random Forest Regression model
- Model trained on historical Walmart sales data
- Performance evaluated using regression metrics

## Power BI Dashboard
The dashboard provides insights on:
- Store performance analysis
- Weekly sales trends
- Holiday vs Non-Holiday sales comparison
- Monthly sales seasonality
- Yearly sales performance
- Top and lowest performing stores
